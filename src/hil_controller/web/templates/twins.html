The inventory is populated from reviewed observations; nothing is created from topology YAML or USB serials automatically. To add units:

  1. esp-usbip-bridge hosts: press Collect from bridge below, review the preview, then Apply.
  2. Linux hosts: run the read-only sysfs collector on the host (command below), then paste or upload its observations.json in the import form.
  3. Offline batch: hil-twins-import --db controller.db --input observations.json (dry-run), then add --apply --backup path/to/new-backup.db.
  4. API: POST /v1/twins/observations/preview then POST /v1/twins/observations.

See docs/digital-twins.md and docs/twin-collectors.md.
