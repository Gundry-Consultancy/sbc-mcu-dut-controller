Serial probe (non-destructive)

Pokes the console ({{ device.serial_port or 'resolved log port' }}) and classifies the response: CircuitPython / MicroPython REPL, safe mode, boot banner, or silent.

BOOTSEL (RP2040 / RP2350)

Holds the BOOTSEL press solenoid (ch {{ device.bootsel_channel if device.bootsel_channel is not none else '—' }}{% if device.bootsel_inverted %}, inverted{% endif %}), power-cycles ch {{ device.solenoid_channel if device.solenoid_channel is not none else '—' }}, releases — the chip cold-boots into its BOOTSEL ROM (RPI-RP2 drive / picotool target).

Flash tools (picotool, esptool)

Picotool (RP2040 / RP2350)

Runs picotool on the DUT host. info/load retry once via the BOOTSEL solenoid when no BOOTSEL-mode device answers. picotool (>= 2.0 for erase) must be installed on the bench host.

Esptool (ESP32 family)

Enters the ROM download loader first (1200-touch → USB-JTAG reset → hub power-cycle), then runs the action. A write power-cycles afterwards to boot the result.

Leave at (default) for esptool's own behaviour; no_reset pairs with a prior stage's --after no_reset for chained operations.
